# CORE MDM releases

Signed Android builds of [CORE MDM](https://coremdm.vercel.app). This repository holds
release files only. The source code is kept elsewhere.

- **Latest app:** [coremdm.apk](https://github.com/MainLoop321/coremdm-releases/releases/latest/download/coremdm.apk)
- **Install it on a phone:** use the web installer at <https://coremdm.vercel.app/install.html>.

Every release is signed with the same key, so each one installs over the one before.
